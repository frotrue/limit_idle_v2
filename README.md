# Limit Idle

## About

Limit Idle is a simple incremental game based on **mathematics**.

## How to Run

Install dependencies and start the local development server:

```bash
npm install
npm run dev
```

Build and preview the production bundle:

```bash
npm run build
npm run preview
# or
npm start
```

## Quality checks

Run unit and facade smoke tests:

```bash
npm test
```

Run a quick balance simulation:

```bash
npm run sim:10m
```

See [docs/TESTING_AND_SIMULATION.md](docs/TESTING_AND_SIMULATION.md) for the full testing and simulation guide.
