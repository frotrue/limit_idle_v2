# Limit Idle

## About

Limit Idle is a simple incremental game based on **mathematics**.

## How to Run

Install dependencies and start the local development server:

```bash
npm install
npm run dev
```

Build and preview the production bundle:

```bash
npm run build
npm run preview
# or
npm start
```
